# ADR-0014: Voice E2EE keyed from MLS

## Context
LiveKit SFrame frame encryption is already wired in (`VoiceE2EEKeyProvider.ts`, `packages/voice_engine_v2`). However, the key is generated by the server and sent in the grant, so it is not end-to-end.

## Decision
- The SFrame key is **derived from the voice channel's MLS Group** using the MLS **exporter**.
- The key **rotates on every join and leave**.
- The P2P mesh mode stays for small calls.
- The server stops issuing `e2ee_key` in voice grants.

## Consequences
This is the best effort-to-value item on the roadmap, because most of the plumbing already exists.
