These routes read and change the account that made the request, a [user object](/http-api/users/#user-object). Every route except [Get current user](#get-current-user) needs a user session and doesn't accept bot or OAuth2 tokens. Changing credentials and the account lifecycle routes need [sudo mode](/http-api/users/mfa/#sudo-mode).

## Guild entry object

The guild an account joined or is visiting after signing up with an invite.

### Structure

| Field | Type | Description |
| --- | --- | --- |
| guild_id | snowflake | The guild the account entered |
| mode | string | `member` when the account joined, `visit` when it is visiting without joining |

## Claim result object

### Structure

| Field | Type | Description |
| --- | --- | --- |
| user | [user](/http-api/users/#user-object) object | The updated account |

## Get current user

<RouteHeader method="GET" path="/v1/users/@me" bot oauth2="identify" />

Returns the current [user](/http-api/users/#user-object) object. An OAuth2 bearer needs the `identify` [scope](/http-api/oauth2/#oauth2-scopes).

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [user](/http-api/users/#user-object) object | The account was returned |
| 403 | [error response](/http-api/#error-response) | `MISSING_OAUTH_SCOPE` when a bearer lacks the `identify` scope |

The rate limit is 40 requests per 10 seconds, on the `user:settings:get` bucket, shared with [Get current user settings](/http-api/users/settings/#get-current-user-settings).

## Modify current user

<RouteHeader method="PATCH" path="/v1/users/@me" />

Changes the account and returns the updated [user](/http-api/users/#user-object) object. A different username or discriminator and `new_password` need [sudo verification](/http-api/users/mfa/#sudo-mode) for a claimed account.

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| username?<sup>1</sup> | string | Username (1-32 ASCII letters, digits or underscores) |
| discriminator?<sup>2</sup> | string \| integer | Discriminator (1-4 decimal digits) |
| global_name? | ?string | Display name (1-32 characters), or null to clear |
| new_password?<sup>3</sup> | string | New password (8-256 characters) |
| password? | string | Current password (8-256 characters) |
| avatar?<sup>4</sup> | ?string | Base64-encoded avatar image, or null to clear |
| banner?<sup>4</sup> <sup>5</sup> | ?string | Base64-encoded banner image, or null to clear |
| bio?<sup>6</sup> | ?string | Biography (1-320 characters), or null to clear |
| pronouns? | ?string | Pronouns (1-40 characters), or null to clear |
| accent_color? | ?integer | Packed 24-bit RGB color (0-16777215), or null to clear |
| timezone?<sup>7</sup> | ?string | IANA timezone identifier (1-128 characters), or null to clear |
| timezone_privacy_flags? | integer | [Profile field privacy flags](/http-api/users/#profile-field-privacy-flags) for the timezone |
| hidden_profile_badges?<sup>11</sup> | array[string] | The full list of [badge keys](/http-api/users/#hiding-badges) to hide from other people, at most 1008 |
| mention_flags? | integer | [Reply mention preference](/http-api/users/#reply-mention-preferences), one of `0`, `1` or `2` |
| mfa_method? | string | Sudo mode method, `totp` or `webauthn` |
| mfa_code? | string | Authenticator or backup code (1-32 characters) |
| webauthn_response? | [WebAuthn assertion](/http-api/users/mfa/#webauthn-assertion-object) object | WebAuthn assertion |
| webauthn_challenge? | string | WebAuthn challenge (1-256 characters) |

<sup>1</sup> Can't be `everyone` or `here` and can't contain `osaca` or `system message`. A name another account has in any letter case returns `USERNAME_ALREADY_TAKEN`

<sup>2</sup> Only bots have discriminators. For a user account it is always `0000`, and any other value returns `DISCRIMINATOR_NOT_SUPPORTED_ON_INSTANCE`

<sup>3</sup> A claimed account that already has a password also sends the current `password` or gets `PASSWORD_NOT_SET`. A breached password returns [`PASSWORD_IS_TOO_COMMON`](/http-api/errors/) when the instance checks for them

<sup>4</sup> Can start with a `data:...;base64,` prefix

<sup>5</sup> Any non-null value needs the animated banner entitlement or returns [`BANNERS_REQUIRE_PREMIUM`](/http-api/errors/)

<sup>6</sup> The `max_bio_length` instance limit also applies and returns `CONTENT_EXCEEDS_MAX_LENGTH`

<sup>7</sup> An unknown identifier returns `INVALID_TIMEZONE_IDENTIFIER`. A first timezone without `timezone_privacy_flags` is visible to `EVERYONE`

<sup>8</sup> Needs the [`STAFF`](/http-api/users/#public-user-flags) flag or returns 403 [`MISSING_ACCESS`](/http-api/errors/)

<sup>9</sup> Only `true` has an effect

<sup>10</sup> Only `false` has an effect

<sup>11</sup> Replaces the saved list. A key that is neither a built-in badge kind nor `custom:{id}` returns `INVALID_FORM_BODY`, and keys of custom badges that no longer exist are dropped


An [unclaimed](/http-api/users/#account-tiers) account that may not customize its profile can only send `new_password` and the sudo fields, and any other field returns [`UNCLAIMED_ACCOUNTS_CAN_ONLY_SET_EMAIL_VIA_TOKEN`](/http-api/errors/). `new_password` can come with `username` to claim the account in one request.

A [limited account](/http-api/users/#account-limitation) can't change profile fields and gets 403 [`ACCOUNT_LIMITED`](/http-api/errors/).

### Images and blocklists

Avatars and banners can be PNG, JPEG, WebP, GIF, APNG, AVIF, HEIC, HEIF, JPEG XL or SVG, up to the `avatar_max_size` limit (10485760 bytes by default). Other formats return `INVALID_IMAGE_FORMAT` and larger images return `IMAGE_SIZE_EXCEEDS_LIMIT`. An animated avatar needs the animated avatar entitlement or returns `ANIMATED_AVATARS_REQUIRE_PREMIUM`.

A username, display name, biography or pronouns that matches the instance blocklist returns 403 [`CONTENT_BLOCKED`](/http-api/errors/). `STAFF` accounts skip the profile blocklist but not the phrase and URL blocklists.

### Change limits

A denied change returns 400 `INVALID_FORM_BODY` with the validation code.

| Change | Allowance | Validation code |
| --- | --- | --- |
| Username or discriminator | 5 per 3 hours | `USERNAME_CHANGED_TOO_MANY_TIMES` |
| Biography | 25 per 30 minutes | `BIO_CHANGED_TOO_MANY_TIMES` |
| Pronouns | 25 per 30 minutes | `PRONOUNS_CHANGED_TOO_MANY_TIMES` |
| Accent color | 25 per 30 minutes | `ACCENT_COLOR_CHANGED_TOO_MANY_TIMES` |
| Avatar | 25 per 30 minutes | `AVATAR_CHANGED_TOO_MANY_TIMES` |
| Banner | 25 per 30 minutes | `BANNER_CHANGED_TOO_MANY_TIMES` |

:::caution[A password change replaces the session]
Sending `new_password` on a claimed account deletes every other session and issues a new token for the request. The response then has the fields of the [password change completion object](/http-api/users/password-and-recovery/#password-change-completion-object).
:::

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [user](/http-api/users/#user-object) object | The account was updated |
| 200 | [user](/http-api/users/#user-object) object with the [password change completion](/http-api/users/password-and-recovery/#password-change-completion-object) fields | A password change replaced the session |
| 400 | [error response](/http-api/#error-response) | The body, image, tag, password, entitlement, change limit or sudo proof is invalid |
| 403 | [error response](/http-api/#error-response) | A claimed account, sudo verification or `STAFF` is needed, or content is blocked |

OSACA sends [User Update](/gateway/events/#user-update) to the account.

The rate limit is 20 requests per minute, on the `user:update` bucket.

## Claim an account

<RouteHeader method="POST" path="/v1/users/@me/claim" />

Sets a password on an unclaimed account so it can sign in from another device. Returns a [claim result](#claim-result-object) object.

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| password | string | The password to set (8-256 characters). A breached password returns `PASSWORD_IS_TOO_COMMON` |

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [claim result](#claim-result-object) object | The account was claimed |
| 400 | [error response](/http-api/#error-response) | The input is invalid, or `ACCOUNT_ALREADY_CLAIMED` |

OSACA sends [User Update](/gateway/events/#user-update).

The rate limit is 5 requests per hour, on the `user:claim` bucket.

## Forget authorized IPs

<RouteHeader method="DELETE" path="/v1/users/@me/authorized-ips" mfa />

Deletes every authorized IP record. Needs [sudo verification](/http-api/users/mfa/#sudo-mode).

### JSON body

The [sudo verification object](/http-api/users/mfa/#sudo-verification-object), which can be empty when you send a sudo token.

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 204 | empty | The records were deleted |
| 403 | [error response](/http-api/#error-response) | `SUDO_MODE_REQUIRED` |

The rate limit is 10 requests per minute, on the `user:authorized_ips:forget` bucket.

## Disable current account

<RouteHeader method="POST" path="/v1/users/@me/disable" mfa />

Disables the account and keeps its data. Needs [sudo verification](/http-api/users/mfa/#sudo-mode), and the response has no `X-OSACA-Sudo-Mode-JWT` header.

### JSON body

The [sudo verification object](/http-api/users/mfa/#sudo-verification-object), which can be empty when you send a sudo token.

:::caution[Every session ends]
Disabling deletes every session of the account, including the one that made the request. Signing in again enables the account unless a temporary suspension disabled it.
:::

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 204 | empty | The account was disabled |
| 403 | [error response](/http-api/#error-response) | `SUDO_MODE_REQUIRED` |

The rate limit is 5 requests per hour, on the `user:account:disable` bucket.

## Schedule current account deletion

<RouteHeader method="POST" path="/v1/users/@me/delete" mfa />

Schedules deletion of the account and deletes every session. Needs [sudo verification](/http-api/users/mfa/#sudo-mode).

### JSON body

The [sudo verification object](/http-api/users/mfa/#sudo-verification-object), which can be empty when you send a sudo token.

:::caution[Signing in cancels the deletion]
The deletion happens 14 days later by default. Signing in before then cancels it, and once erasure starts it can't be cancelled.
:::

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 204 | empty | The deletion was scheduled |
| 400 | [error response](/http-api/#error-response) | The account owns a guild, `USER_OWNS_GUILDS` |
| 409 | [error response](/http-api/#error-response) | `CONFLICT` when erasure has started |


The rate limit is 5 requests per hour, on the `user:account:delete` bucket.

## Accept current policies

<RouteHeader method="POST" path="/v1/users/@me/terms-acceptance" />

Records acceptance of the current terms of service and that the privacy policy was shown, and returns the updated [user](/http-api/users/#user-object) object.

### JSON body

The body is an empty object.

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [user](/http-api/users/#user-object) object | The acceptance was recorded |
| 400 | [error response](/http-api/#error-response) | The body is not a JSON object |

OSACA sends [User Update](/gateway/events/#user-update).

The rate limit is 20 requests per minute, on the `user:update` bucket.

## Preview profile badges

<RouteHeader method="POST" path="/v1/users/@me/profile-badges/preview" />

Returns the account's [profile badges](/http-api/users/#profile-badge-object) as others would see them with the given settings, and every badge the account holds with whether those settings hide it. Nothing is saved.

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| hidden_profile_badges? | array[string] | Preview with these [badge keys](/http-api/users/#hiding-badges) hidden |


### Response body

| Field | Type | Description |
| --- | --- | --- |
| profile_badges | array[[profile badge](/http-api/users/#profile-badge-object) object] | The badges other people would see, in display order |
| own_badges | array[[own profile badge](#own-profile-badge-object) object] | Every badge the account holds, in display order |

### Own profile badge object

A [profile badge](/http-api/users/#profile-badge-object) with a `hidden` field.

| Field | Type | Description |
| --- | --- | --- |
| key | string | The badge's identity, and the value to put in `hidden_profile_badges` |
| kind | string | The badge type |
| label | string | The badge description in your locale |
| asset | ?string | The badge image hash, or null for a text badge, a custom badge or a built-in badge with a replaced image |
| asset_url | ?string | The image URL of a custom badge or of a built-in badge with a replaced image |
| aspect_ratio | ?number | The image width divided by its height |
| caption | ?string | The short badge text, such as `#42` |
| href | ?string | The URL a click opens |
| small_asset? | string | The image hash for 20 pixels and smaller |
| count? | ?integer | A number the badge stands for |
| accessible_label? | ?string | The label for screen readers |
| details? | ?[badge details](/http-api/users/#badge-details-object) object | The tooltip content |
| hidden | boolean | Whether the badge key is in the previewed `hidden_profile_badges` |

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | response body | The badges were returned |

The rate limit is 100 requests per 10 seconds, on the `user:profile::target_id` bucket.
