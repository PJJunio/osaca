Accounts sign in with a username and a password or passkey. These routes change the password and manage the recovery kit, which lets the person set a new password without signing in. Every route needs a user session, and bots can't use them.

## Password change completion object

The new session after a password change. OSACA ends every session on the account, including the one that made the request, and you send later requests with this `token`. [Modify current user](/http-api/users/current-user/#modify-current-user) adds the same fields when it changes the password.

### Structure

| Field | Type | Description |
| --- | --- | --- |
| token | string | The token for the new session |
| auth_session_id_hash | string | The base64url hash of the new session ID |

## Recovery kit status object

### Structure

| Field | Type | Description |
| --- | --- | --- |
| has_recovery_kit | boolean | Whether the account has a recovery kit |
| created_at | ?ISO8601 timestamp | When the current kit was created |

## Recovery kit object

A new recovery kit, whose key [Recover an account](/http-api/authentication/#recover-an-account) uses to set a new password without signing in.

### Structure

| Field | Type | Description |
| --- | --- | --- |
| recovery_key | string | The key, 8 groups of 4 Crockford base32 characters joined by `-` |
| created_at | ISO8601 timestamp | When the kit was created |

## Set a new password

<RouteHeader method="POST" path="/v1/users/@me/password" mfa />

Changes the password after [sudo mode](/http-api/users/mfa/#sudo-mode) and returns a [new session](#password-change-completion-object). It also deletes the account's recovery kit. A password found in known breaches fails with `PASSWORD_IS_TOO_COMMON`.

### JSON body

The body extends the [sudo verification object](/http-api/users/mfa/#sudo-verification-object) with `new_password`.

| Field | Type | Description |
| --- | --- | --- |
| new_password | string | The new password (8-256 characters) |

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [password change completion](#password-change-completion-object) object | The password was changed |

OSACA sends [Auth Session Change](/gateway/events/#auth-session-change) with the old and new session ID hashes.

The rate limit is 10 requests per minute, on the `user:password:update` bucket.

## Get recovery kit status

<RouteHeader method="GET" path="/v1/users/@me/recovery-kit" />

Returns whether the account has a recovery kit.

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [recovery kit status](#recovery-kit-status-object) object | The status was returned |

The rate limit is 20 requests per minute, on the `user:recovery_kit:get` bucket.

## Create a recovery kit

<RouteHeader method="POST" path="/v1/users/@me/recovery-kit" mfa />

Creates a recovery kit after [sudo mode](/http-api/users/mfa/#sudo-mode) and makes the previous key stop working. Show the key to the person before you discard the response, because OSACA never returns it again.

### JSON body

The body is the [sudo verification object](/http-api/users/mfa/#sudo-verification-object).

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [recovery kit](#recovery-kit-object) object | The kit was created |

The rate limit is 6 requests per minute, on the `user:recovery_kit:create` bucket.
